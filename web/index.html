Why it exists

A benchmark measures speed. It has no way to notice when the fastest answer is wrong. ATHERYN spends more experiments to make fewer claims — each one scoped, replicated and attacked before it is allowed to stand.

The loop

From question to scoped conclusion.

01 / 07
  1. 01

    A question, and a budget

    A question in a registered domain, with hard limits on experiments, compute and time. The mission spec is validated before anything runs.

    CREATED → VALIDATING → PLANNING

  2. 02

    Competing hypotheses

    Rival explanations are held at once, each paired with predictions a machine can check. A model may propose more; proposals earn nothing for free.

    FORMING_HYPOTHESES

  3. 03

    Reproducible experiments

    Generated from audited templates, run in a confined subprocess, and kept forever — code, seed, config, environment and raw results.

    DESIGNING_EXPERIMENT → EXECUTING

  4. 04

    Conservative analysis

    A difference is decisive only with enough trials, a wide separation and a real margin. Everything else is recorded as inconclusive.

    ANALYZING → UPDATING_KNOWLEDGE

  5. 05

    Independent replication

    The critic refuses single-experiment support. Anything that looks true is re-run with new seeds in a separately spawned process.

    CRITICIZING → REPLICATING

  6. 06

    Falsification probes

    Survivors are attacked at twice the tested size and on input regimes they have never seen. Failing a probe downgrades the claim.

    FALSIFYING

  7. 07

    A scoped conclusion

    What survived, the conditions it holds under, a full dossier — and an explicit stop reason. Never “it depends”, never unbounded.

    What counts as decisive

    Three conditions. All of them.

    5

    trials per side

    The minimum before any ordering is called.

    3×

    combined standard error

    The gap between two means must exceed it.

    10%

    relative margin

    Of the faster mean — small wins are not wins.

    Anything weaker is inconclusive — neither support nor refutation. No p-values: at these trial counts they would imply precision the data lacks.

    Honest by construction

    What ATHERYN is not.

    • A general “autonomous scientist”.

      It runs computational experiments in registered domains — sorting and shortest paths, today.

    • A web crawler.

      It retrieves only URLs you approve. Everything retrieved is untrusted input and stays speculation.

    • An unrestricted code runner.

      It executes code generated from its own audited templates — never model-written or web-derived code — under user-space limits, not kernel isolation.

    • An oracle.

      Generated prose is never evidence. A model may propose; proposals face the same experiments as everything else.

    • Unsupervised.

      Autonomy chooses among already-permitted actions inside limits you set. No daemon, no background service.
